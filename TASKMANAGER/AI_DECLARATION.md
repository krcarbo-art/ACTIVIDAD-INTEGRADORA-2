# Declaración de uso de Inteligencia Artificial

**Proyecto:** TaskManager – Aplicación de Gestión de Tareas  
**Institución:** Universidad ECOTEC  
**Herramienta utilizada:** ChatGPT de OpenAI

Durante el desarrollo del proyecto TaskManager, utilicé ChatGPT como herramienta de apoyo para **verificar errores, revisar la estructura del código y mejorar algunas líneas de programación**.

La herramienta me permitió identificar problemas de sintaxis, revisar la correcta utilización de instrucciones y optimizar fragmentos de código en HTML, CSS y JavaScript.

**Ejemplos de consultas realizadas:**

1. "Revisa mi código y ayúdame a identificar los errores que aparecen en la consola".
2. "Mejora las líneas de código que tengo actualmente, conservando las funcionalidades de mi aplicación".

ChatGPT también proporcionó sugerencias de código que revisé e incorporé al proyecto. La organización de los archivos, la integración de los cambios y las comprobaciones se realizaron mediante Visual Studio Code y el navegador.

El uso de inteligencia artificial tuvo como finalidad apoyar la revisión, corrección y mejora del código durante el desarrollo de TaskManager.
